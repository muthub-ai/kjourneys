Method & data

Where the numbers come from

Everything on this page renders from one validated data product, kjourneys, imported from the MI workbook and checked on every change by a JSON Schema, an integrity checker and negative test cases.

Report as received

Files are kept exactly as delivered, and every build re-checks each sha256. This page is built from the Excel workbook.

Evidence levels

The ontology's basis and confidence are derived from MI's six levels; the original level is kept on every record.
